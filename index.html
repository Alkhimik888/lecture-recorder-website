What you don't have to do.

A useful product is often defined by what it leaves out. Five things this one happily refuses.

No sign-up

Install and click. No account, no email, no onboarding form to fill.

No API keys, no settings to fight with

AI Notes run on our side. You never see a config screen, never paste a token.

Recording is always unlimited

Two-hour video or three-hour session — same file, same quality. AI Notes have 300 min / month free.

Audio deleted in 60 seconds

When you stop, audio briefly visits our server to be processed, then it's gone.

No data tied to your name

Usage is tracked by an anonymous install ID on your machine. No email, no profile.

No telemetry on recording

Zero outbound network requests during recording itself. The file lands locally first.

Privacy.

Recording stays local. Audio briefly visits our server only for AI Notes, then it's gone.

Privacy summary

The media file is captured by Chrome's built-in tabCapture API and written straight to your Downloads folder. We never see it.

For AI Notes, audio is uploaded over HTTPS to our backend, processed, and returned to you as a .docx. The audio is deleted from our server within 60 seconds.

No signup, no account, no email collected. Usage is tracked by an anonymous install ID stored on your device. Read the full privacy policy →
